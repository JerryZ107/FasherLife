# FasherLife · 钓鱼佬日常

休闲 **钓鱼 + 水族馆养成** 的 H5 Demo。  
免费玩家能走完整循环；珍珠买的是时间和便利，不买更高数值。

本仓库是可玩的垂直切片：**16 鱼 · 2 渔场**（乡村池塘 / 清溪）· 北京自然日结算。

---

## 核心循环

```text
选渔场 → 甩竿等漂 → 滑块搏斗 → 进鱼筐
                ↓
        入缸喂养 / 鱼行售卖 / 做菜补体力
                ↓
        买饵 · 装备 · 扩建 · 再出钓
```

| 自己甩竿 | 挂机 |
| --- | --- |
| 只扣 **鱼饵** | 必须同时有 **鱼饵 + 体力** |
| 手感与上钩 | 日预算产鱼 |

## 快速开始

需要 **Node.js 18+**。

```bash
git clone git@github.com:JerryZ107/FasherLife.git
cd FasherLife
npm install
npm run dev
```

浏览器打开终端里的地址（默认 `http://localhost:5177/`）。

开发服已开启局域网访问（`host: true`）。手机与电脑同一 Wi‑Fi 时，用终端打印的 `Network` 地址打开，例如：

```text
http://192.168.x.x:5177/
```

> IP 会随路由器 DHCP 变化，以当次 `npm run dev` 输出为准。

```bash
npm run build    # 生产构建
npm run preview  # 预览 dist
```

### 账号与存档

- 登录页分开 **登录 / 注册**，账号全柜唯一。
- 存档在游戏服务的 `data/account-book.json`（已 gitignore，不进仓库）。
- 可勾选「记住账密」（只存在本机浏览器）。
- 换设备：同一账号密码 + 连着同一次打开的本地服务即可接档。

## Demo 里有什么

- **水族馆主页**：木框鱼缸、点鱼喂食 / 配偶 / 售卖、缸位扩建、托管
- **新手引导**：喂食 → 卖鱼 → 图鉴 → 钓鱼 → 入缸 → 做菜吃菜 → 圣殿排行参观（可跳过、可重温）
- **钓鱼**：坐下 · 上滑甩竿 · 下滑收竿 · 右侧滑块追鱼；挂机；杂物 / 漂流瓶
- **背包**：鱼竿配件、鱼饵、板凳、鱼筐、道具（菜 / 饮料）、服装、书籍 / 图鉴
- **商城 / 鱼行**：鱼粮饵料、礼包、系统货与玩家挂售
- **任务**：新手引导、新手任务、限时、常驻
- **圣殿排行**：参观假钓友水族馆、沾欧气
- **PWA**：可加到主屏幕；调试浮球可改金币 / 珍珠 / 游戏时速

## 产品原则（摘要）

1. **付费买时间，不买更强的竿** —— 同品质金币 / 珍珠通道数值持平  
2. **鱼饵 ≠ 鱼食** —— 出钓扣饵，缸里扣同品质粮  
3. **手动不扣体力；挂机饵+体力双闸门**  
4. **小游戏难度只跟鱼品质走** —— 饵和欧气只改上钩，不改滑块强度  
5. **Demo 验证循环，不验证图鉴量** —— 16 鱼 / 2 场足够

完整取舍见 [一页设计说明.md](./一页设计说明.md)。术语以 [CONTEXT.md](./CONTEXT.md) 为准。
