# ADR-011：Demo 分两阶段交付与 v0.1 范围

- 状态：已接受
- 日期：2026-08-18
- 关联：ADR-001 玩法设定、ADR-003 商业化定位

## 背景

ADR-001 描述的是完整产品（水族馆养成 + 钓鱼 + 鱼行交易 + 配对孵化遗传 + 装备五件套改装 + 鱼缸扩建 + 潜入潜行小游戏 + 榜单/配偶/个性），一次性全做等于 4~6 个月全职，与"验证核心玩法手感"的 Demo 目标冲突。

## 决策

Demo 分两阶段：

- **v0.1（MVP，~6 周）**：核心三件套（水族馆养成 + 钓鱼小游戏 + 装备/商城经济）+ 挂机钓鱼 + 鱼行交易市场 + 图鉴框架（16 鱼）+ 新手任务引导线。潜行/配对/改装/扩建做占位按钮，可见不可用。
- **v0.2（广度版，当前 Demo）**：补配对孵化（无遗传、仅配偶下卵）、鱼竿五件套改装、水族馆缸位扩建（金币开工 + 工期，珍珠/广告只加速；鱼缸按品质购买，见 ADR-015）、潜入潜行小游戏。图鉴维持 **16 鱼 / 2 地图点**（乡村池塘、清溪，各有独立立绘；ADR-002 的 62 鱼附录不进本 Demo）。榜单做轻量参观+欧气。服装仅外观、增益书籍、自定义搭配、限时/常驻任务、礼包可玩。个性/性格/配偶观仍占位。存档版本升至 v6。

**游戏内时间尺度**：1 游戏天 = 北京时间自然日（当天 0 点到次日 0 点）。喂食、健康、托管、孕期、孵化、饱腹、月卡都按跨过的 0 点结算。求偶香催产仍是 5 现实分钟，不走游戏天。

## 理由

- v0.1 聚焦"钓鱼+养鱼好不好玩"，这是产品差异化所在；潜行小游戏是异质玩法，对验证核心手感无帮助，留到 v0.2。
- 图鉴全 62 鱼是内容量产工作，与"验证手感"无关；v0.1 做 16 鱼（2 渔场完整名单）足以展示框架。
- 养鱼循环按北京自然日走，和月卡、孵化天数一致；不再用「1 分钟 = 1 天」加速。

## 影响

- v0.2 装备系统拆五件套改装；鱼竿购买发放套件，散件可单买后混搭。
- 时间尺度按北京自然日结算，方便和月卡、孵化工期对齐；求偶香催产仍用现实 5 分钟。
- 存档版本升至 v6：性别/配对/鱼卵/多缸（品质+缸位）/组件/服装/书籍/自定义搭配/缸位扩建排期/任务。
