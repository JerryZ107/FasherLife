# ADR-017：后期双路线（钓鱼 / 育卵）

- 状态：已接受
- 日期：2026-08-20
- 关联：ADR-001 玩法设定、ADR-001 双货币、ADR-003 商业化定位、ADR-011 Demo 范围、ADR-015 鱼缸与鱼卵、ADR-018 健康值与性格
- 修正：无。把 ADR-003「后期配对/孵化赚大量金币」落成产出、消耗、交接规则。

## 功能分析

后期若只有钓鱼进账，竿和渔场卡会很快买完；育卵若没有维持费，又会替代钓鱼。所以做成两条产销管道而不是职业：钓鱼用饵、票、竿换爆发和种类，育卵用鱼食、托管、缸位换稳定日产，新种只能钓或买。托管按条满额收，避免满缸极品印钞。Demo 只验证这条流水，不把日入做到上万。

## 1. 范围

存档没有「钓鱼玩家 / 育卵玩家」标记。同一账号可同时出钓和养鱼。「钓鱼线 / 育卵线」只用来拆金币从哪进、往哪出。

## 2. 钓鱼线：产出、限制、消耗

**产出**

| 动作 | 金币 | 公式 |
| --- | --- | --- |
| 鱼筐「售卖」给鱼行 | 立即到账 | `FISH_DEFS.sellPrice`（筐里无健康，按 100%） |
| 缸内鱼「售卖」给鱼行 | 立即到账 | ADR-018 健康修正价 |
| 挂机 | 鱼进筐，卖了才有钱 | 每 `IDLE_MS_PER_CAST`（现 10s）消耗 1 饵，按渔场池抽鱼。体力切片（ADR-016）另扣体力；手动仍只扣饵。 |

**限制（同时生效）**

- 每次下竿扣 1 个当前鱼饵；饵空不能钓、不能挂机。挂机在体力切片启用后还要求体力够支付该次品质消耗（ADR-016）。
- 付费渔场：无卡则门票或潜入；有卡跳过。高档渔场卡/票定价见 ADR-003（金币，不收珍珠）。
- 鱼筐满（条数或重量）时手动钓要换鱼；挂机自动用差的换好的。
- 上钩后小游戏失败则这条不计产。

**金币消耗（钓鱼线货架）**

| 项 | 现表（可调） |
| --- | --- |
| 鱼饵 | 普通 1 … 极品 1000 / 个 |
| 清溪门票 / 月卡 | 15 / 300（后续高档卡可到数十万） |
| 金币竿 | 玻璃钢 120、钛合金 800、碳素 3500、玄铁 15000 |
| 散件 | 随品质，见 `equipmentDefs` |
| 板凳 / 鱼筐 | 折叠凳 60、中筐 100、大筐 600 |

竿、散件、筐、凳只改遛鱼，不改缸内产卵。

## 3. 育卵线：产出、限制、消耗

**产出流水**

1. 同缸自动配对成功 → 写入 `pairId`，开始孕期（ADR-018）。
2. 孕期满（或求偶香倒计时结束）→ 该缸底 +1 卵。每缸卵上限仍为 **6**。
3. 点卵付金币开工孵化 → 6 或 7 游戏天后出苗。
4. 子代入缸，可再配、可卖。

稳态日产卵数（单缸）：

```
配对对数 = floor(活鱼数 / 2)（配偶上限 1，且能互相通过爱情观）
日产卵 ≈ 对数 / 该对孕期天数
         且不超过 6 - 当前缸底卵数
```

健康 ≤60 的对不产卵，计入 0。

**金币消耗（育卵线货架）**

| 项 | 何时扣 | 现表 |
| --- | --- | --- |
| 同品质鱼食 | 喂 1 条 1 天 | 普通 1 … 极品 500 |
| 托管 | 开托管时每个游戏天按缸内活鱼品质加总 | 普通 0 / 优良 10 / 稀有 50 / 珍贵 150 / 极品 600 |
| 求偶香 | 使用时 | 金币 8～400；珍珠雾 1～4 |
| 孵化开工 | 点卵 | 普通 5 … 极品 400（取亲本较高品质） |
| 买缸 | 有空缸位时 | 陶泥 80 … 玄铁缸 8000 |
| 扩建缸位 | 开工 | 120 金 / 2 游戏天 |

托管费按条、按品质全额收，不做托管折扣。

## 4. 两条线交接

| 资源 | 从哪来 | 规则 |
| --- | --- | --- |
| 新种类 | 野外钓获，或鱼行购买（系统货 / 玩家挂售） | 图鉴可预览全部种类；亲本里没有的种孵不出来 |
| 子代种类 | 亲本 | 50% `parentA.defId` / 50% `parentB.defId` |
| 子代性别、性格、爱情观 | 不遗传 | 各独立随机（ADR-018） |
| 公母缺口 | 再钓或去鱼行买 | 自动配对仍要求一公一母，玩家不能指定对象 |

禁止：孵化随机出亲本都没有的 `defId`。禁止：用图鉴「已阅」当孵化资格。

## 5. 每个游戏天结算顺序

游戏天 = 北京自然日（当天 0 点到次日 0 点）。离线跨过几个 0 点就结算几天。

接在 ADR-001 喂食扣血流程上，`settleDays` 顺序：

1. 托管则尝试自动喂食、扣托管费（金币不够则关托管，当天未喂的照常掉健康）。
2. 未喂活鱼扣健康；健康到 0 则死亡并 `breakPair`。
3. 自动配对（爱情观硬过滤 + 软骰 + 求偶香成功率，ADR-018）。
4. 已结成的对走孕期：≤60 暂停；否则剩余天数 −1；到 0 且缸卵 <6 则下卵。
5. 已开工的卵：`readyDay` 到期则可取。
6. 扩建到期 +1 缸位。

求偶香的 5 现实分钟产卵不走游戏天，见 ADR-018。

## 6. 日入目标（填表用）

毛收入 = 当天「售卖给鱼行」+ 挂售成交。  
净利 = 毛收入 − 鱼食 − 托管 − 饵 − 门票 − 孵化开工 − 求偶香 − 扩建。

| 阶段 | 毛收入 / 天 | 净利 / 天 | 钓鱼侧典型 | 育卵侧典型 |
| --- | --- | --- | --- | --- |
| 前期 | 100～300 | ≈ 毛利 | 池塘挂机 + 筐卖普通/优良 | 1 对，孕期长 |
| 中期 | 800～2000 | 约一半毛利 | 清溪 + 中档饵 | 2～4 对，自己喂优良/稀有 |
| 后期 | 5000～10000 | 2000～6000 | 高档渔场 | 多缸、健康 ≥90、不全开极品托管 |

Demo（16 鱼，卖价最高 100）不把日入做到上万。正式档珍贵/极品卖价用净利反推：先扣鱼食和托管再定价。

珍珠：同品质装备数值持平；珍珠/广告只砍扩建、孵化、孕期等待。不提高卖价、不改爱情观。

## 实现

- `pickOffspringDefId` 保持二选一；性格/爱情观/性别在生成实例时另掷。
- 鱼行系统货须能卖出 Demo 未钓到的种（至少若干条）。
- 售价、孕期、配对、求偶香倒计时以 ADR-018 为准。
