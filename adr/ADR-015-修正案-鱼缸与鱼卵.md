# ADR-015：修正案 · 配偶鱼卵、鱼缸品质、水族馆扩建、求偶香

- 状态：已接受
- 日期：2026-08-19
- 关联：ADR-001 玩法设定、ADR-003 商业化定位、ADR-011 Demo 范围
- 修正：ADR-001 中「扩建加缸内容量」「玩家指定一公一母配对」不再有效
- 后续修正：爱情观、孕期、孵化工期、求偶香「买时间」见 [ADR-018](./ADR-018-健康值与性格表现.md)；后期双路线见 [ADR-017](./ADR-017-双路线设定.md)

## 决策

### 1. 同缸自动配对；只有配偶下卵

同缸未配对的一公一母，每个游戏天先过双方爱情观，再按种类差距 + 品质差距软骰，成功则结为配偶，并出现在**配偶表**。玩家不能指定对象。

**只有配偶才会在缸底下卵**（含自动结成的）。没有配偶不下卵。解除或一条死亡后不再下新卵；已经在缸底的卵还在。鱼行买来/下架回来的卵是交易货，不要求自己缸里有对应配偶。

爱情观、孕期与孵化工期改由 [ADR-018](./ADR-018-健康值与性格表现.md) 规定。种类/品质差距仍作软骰；求偶香压软拒绝、买孕期，**不改**爱情观判定。

孵化仍是金币开工；珍珠或看广告只加速工期（单价见 ADR-018）。子代随机像某一亲本，无性状遗传。

### 2. 鱼缸分品质，需要买

鱼缸是带品质的商品（普通 / 优良 / 稀有 / 珍贵 / 极品），金币通道与珍珠通道同品质容量持平。品质决定**这一口缸能养多少条鱼**，本 Demo 不按鱼的品质限制入哪口缸。

开局送一口普通缸。再要缸，必须先有空**缸位**，再花钱买对应品质的缸。

### 3. 扩建只加水族馆缸位

**扩建**加的是水族馆能摆下几口缸（缸位），不是把现有缸撑大。

开工花金币、等工期；珍珠或看广告只加速。缸位空出来之后才能买新缸。鱼缸礼包若当时没有缸位，附赠一个缸位。

### 4. 求偶香（吸引力）

求偶香是新消耗品，不和鱼饵/鱼食混用。用来提高当天自动配对成功率，有上限（约 0.92），不能让品质差四档必成。

- **金币**：喂给**一条鱼**，按品质分档，持续若干游戏天，这条更容易被自动配上。
- **珍珠**：喷**整缸**，持续若干游戏天，缸内所有未配对鱼都提成。同品质通道更强/更久，不额外加「必成」。

这是配对线的商机：玩家不点谁配谁，花钱提高自动结成的速度。

## 理由

原先「扩建 = 加条数」和「买新缸」叠在一起，玩家分不清空间花在哪。缸位归水族馆、容量归缸的品质，加速仍绑在扩建工期上，和 ADR-003「扩建/孵化加速变现」一致。

关掉自动配对后配偶表是空的、卵像凭空出现。自动配对 + 配偶表列出所有一对，卵才有来处。指定配对从玩法里拿掉，把付费点放到求偶香上，符合「肝金币 / 充珍珠买时间与成功率」。

## Demo 数值（可调）

- 缸位：起始 1；每次扩建 +1；开工 120 金 / 2 游戏天；加速 2 珍珠或看广告。
- 缸容量：普通 6 / 优良 10 / 稀有 14 / 珍贵 18 / 极品 24。
- 金币求偶香：成功率 +0.15～+0.35，持续 2～4 天。
- 珍珠整缸香氛：成功率 +0.25，持续 3 天。
