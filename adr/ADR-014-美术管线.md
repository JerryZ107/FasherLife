# ADR-014：美术管线（AI 生图 + Q版卡通风）

- 状态：已接受
- 日期：2026-08-18

## 背景

Demo 目标含"给上线/投资人演示"且要"打磨度"，美术不能是纯色块占位。但 16 鱼 + 装备 + UI + 场景全量产是 4~8 周专职工作，Demo 阶段需捷径。

## 决策

- **美术来源：AI 生图 + 人工筛调**。用 Midjourney/Stable Diffusion 生成，人工筛风格一致的、调色修瑕。
- **风格：Q版卡通风**。大头小身、饱和色、表情化。休闲品类主流，AI 生图一致性最稳，UI 配色好搭。
- **统一 prompt 模板**：固定风格描述前缀（如 "chibi cartoon style, flat saturated color, white background, centered, game asset"）+ 主体描述，确保 16 鱼 + 装备风格一致。
- 资产规格：鱼 PNG 透明底、512×512；装备图标 128×128；UI 走矢量/SVG 自绘，不依赖 AI。
- **人物与鱼同一套 Q 版语言**：大头、厚描边、亮眼睛、软高光。服装分套用矢量绘制（男女两版），不靠立绘色相旋转，也不复用保安色块。

## 理由

- AI 生图是 Demo 阶段拿到"能看"资产的最快路径，外包约稿慢且贵、免费素材包风格难统一、自做矢量量产 16 鱼工作量大。
- Q版卡通风在 AI 生图上一致性最可控（写实风易跑偏、国风水墨与休闲调性冲突、扁平矢量缺鱼质感），且与"休闲养成"调性契合。
- UI 用矢量自绘而非 AI：UI 图标需要精确像素对齐与可缩放，AI 生图不适合；只在鱼和装备插画上用 AI。

## 影响

- 需建立 prompt 模板仓库与资产命名约定（如 `fish_{id}.png`、`rod_{id}.png`），便于 v0.2 扩到 62 鱼时复用模板。
- 资产先占位（灰色剪影）跑通流程，AI 生图作为独立流水线并行补图，不阻塞代码开发。
