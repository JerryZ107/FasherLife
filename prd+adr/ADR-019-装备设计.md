# ADR-019：装备设计 · 手杆即鱼竿、四件组件

- 状态：已接受
- 日期：2026-08-22
- 关联：PRD-001 玩法设定、ADR-003 商业化定位、ADR-010 数值克制、ADR-012 钓鱼小游戏
- 修正：PRD-001 / ADR-012 中「鱼竿五件套、手杆是其中一件可改装散件」不再有效

## 背景

原先把鱼竿拆成手杆、渔线轮、鱼线、鱼钩、浮漂五件，手杆当散件买、当散件改装。玩家会以为买了竿还要再买一根手杆，商城也出现「手杆」货架。实际钓鱼时竿就是握在手里的那根杆。

## 决策

**鱼竿就是手杆。** 装备页/出钓槽里的「鱼竿」是一根完整的手杆，有品质、有系数。组件只有四件：**渔线轮、鱼线、鱼钩、浮漂**。不能再买、再改装「手杆」散件。

买下一根竿，送该竿配套的四件组件。换竿会先换上这套四件，之后仍可用已拥有的散件改装。同品质金币竿与珍珠竿系数完全持平（ADR-003）。

板凳、鱼筐、服装、书籍职责不变：板凳/手稳手册加玩家滑块尺寸，不进手杆系数。

## 机制（小游戏里各管一档）

难度仍由**鱼品质**驱动（ADR-012）。装备只抵消手感，不改上钩概率。

| 部位 | 管什么 | 结算 |
| --- | --- | --- |
| **手杆（鱼竿）** | 把下面四件的数值乘上系数 `c` | 装备哪根竿用哪根的 `c` |
| **渔线轮** | 玩家滑块跟手速度 | `灵敏度 × c` |
| **鱼线** | 进度涨、跌都变快 | `进度倍率 × c`（双刃） |
| **鱼钩** | 鱼滑块变大，更好套 | `鱼滑块加成 × c` |
| **浮漂** | 上钩后能反应多久 | 窗口 = `1800 + 浮漂ms × c` |
| **板凳 / 书籍** | 玩家滑块尺寸 | 加法，不乘 `c` |

不把「更大的玩家滑块」塞进手杆：那是板凳的活。手杆只做总成，四件各管一项，改装才有取舍。

鱼线涨跌同倍率是刻意的：好线收得快，脱钩也快，不能靠一条线把失败抹掉。

## 数值（本 Demo）

品质阶：普通 / 优良 / 稀有 / 珍贵 / 极品。同档金币通道与珍珠通道数值相同。

**手杆系数 `c`**

| 品质 | c |
| --- | --- |
| 普通 | 1.00 |
| 优良 | 1.05 |
| 稀有 | 1.10 |
| 珍贵 | 1.15 |
| 极品 | 1.22 |

本 Demo 上限 1.22，不再往上堆。

**四件组件（未乘 `c` 的底值）**

| 品质 | 渔线轮 灵敏度 | 鱼线 进度倍率 | 鱼钩 滑块加成 | 浮漂 窗口 ms |
| --- | --- | --- | --- | --- |
| 普通 | 1.00 | 1.00 | 0 | 1200 |
| 优良 | 1.20 | 1.15 | 0.03 | 1400 |
| 稀有 | 1.40 | 1.30 | 0.06 | 1600 |
| 珍贵 | 1.60 | 1.45 | 0.09 | 1800 |
| 极品 | 1.85 | 1.65 | 0.12 | 2000 |

月卡赠渔线轮：灵敏度 1.28（优良和稀有之间），不进商城。

满配上限（极品竿 × 极品四件）：灵敏度约 2.26、进度约 2.01、鱼滑块 +0.15、上钩窗口约 4.2 秒。极品鱼底滑块 0.10，钩满也到不了普通鱼的 0.28，装备不能把高档鱼打成入门难度（ADR-010）。

**板凳**：木板凳 +0；折叠凳玩家滑块 +0.04。基础玩家滑块 0.22。手稳手册另 +0.03。

**竿价（手杆本体）**：竹节 0 / 玻璃钢 120 金或流光 2 珍珠 / 钛合金 800 金或 8 珍珠 / 碳素 3500 金或 18 珍珠 / 玄铁 15000 金或 48 珍珠。金涡纹竿仅礼包。散件价低于同档整竿，鼓励先买竿再补改装。

## 理由

竿和手杆是同一根东西，拆成两件货会让人付两次。系数留在竿上，四件仍可混搭，改装深度还在。数值按品质一档一档加，不用珍珠买战力，也不让满配抹平极品鱼。

上钩窗口不再用 3200ms 托底：托底会让普通浮漂和优良浮漂没差别。改为 `1800 + 浮漂×c`。

## 影响

- 商城「组件」只卖渔线轮 / 鱼线 / 鱼钩 / 浮漂。
- 旧存档里的手杆散件：换成对应品质的竿（已有则忽略），并从组件栏拿掉。
- ADR-012「五件套」改为「手杆 + 四件组件」。
