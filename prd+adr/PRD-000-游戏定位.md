# PRD-000：游戏定位

1、玩家主要做什么？
    通过 钓鱼/孵化/购买 来获取更多更好的鱼，来装填自己的水族馆，并提升自己的榜单排名

2、玩家的短期和长期目标是什么？
    短期（跑通基础循环）：
        a.钓到鱼：
            放入水族馆的鱼缸里
            售卖获取金币
            做菜加体力
        b.接触挂机玩法，了解体力机制
        c.了解装备的增益效果，购买适配自己的装备
        d.从免费渔区去更高级渔区钓鱼，接触办卡/购票/潜入玩法

    中期（拓展玩法）：
        a.了解配偶与孵卵机制，学会通过策略产出自己想要的鱼卵
            钓取/租借/购买 种鱼
            使用求偶香 强化种鱼魅力
            结成配偶（配错了可以换缸拆散）
            购买特殊鱼粮提高产卵效率
            购买孵化香 加速孵化
        b.了解好友机制，学会加好友/约好友一起钓鱼（demo未做）
            钓鱼区点击玩家“加好友”/搜索界面通过UID加好友
            通过通讯录选择发送 即时邀约/预约
            点击邀约自动进入指定渔区（可以为对方买票占位，也可以双双潜入）
            钓鱼时可以发送表情包（玩家头顶冒出）
            付费装备/道具 可赠送

    长期（提升用户黏性）：
        排行榜：水族馆内的鱼会转为声望值，提升玩家的钓鱼佬圣殿榜单排名
        赛季（demo未做）：持续更新 地图与鱼种，解锁不同的任务与成就
        
    最终：通过给鱼起名、好友钓鱼与钓鱼佬笔记，建立情感依赖

3、玩家为什么觉得游戏好玩？
    成就感：
        自己水族馆拥有琳琅满目的各色鱼缸与鱼群
        钓取/孵化 高级品种鱼
        卖鱼获得大量游戏资源
    亲密感：
        给鱼取名
        观察/点击不同鱼的不同表现（基础规则+随机性格 涌现）
        孵化鱼卵
        笔记记录钓鱼生活
        与好友一同钓鱼（暂未做好友系统）
    刺激感：
        越过警戒线偷偷溜进钓鱼区钓鱼
        鱼的品质越高，钓取难度越高，卖的也越贵（高风险高回报）
    探索感：
        不同地区拥有不同鱼种
        鱼拥有不同的性格与配偶观表现
        不同鱼种有不同的鱼饵偏好与玩法数值
    不确定性中的掌控感：
        鱼群随机配偶，但可以用求偶香提升特定鱼的吸引力
    策略感：
        挂机还是实操（装备选择不同）
        主要玩法：钓鱼（休闲操作）还是孵鱼（休闲养成）
        如何最大化各个收益（挂机、养鱼等玩法）

4、用一句话描述游戏
    可挂机、可联机、可养鱼的钓鱼主题的竖屏休闲手游。
