# ADR-014：美术（AI 生图 + 双套人物语言）

## 决策

- **美术来源：AI 生图 + 人工筛调**。用 Midjourney/Stable Diffusion 生成，人工筛风格一致的、调色修瑕。
- **鱼立绘：Q版卡通风**。大头小身、饱和色、表情化。休闲品类主流，AI 生图一致性最稳，UI 配色好搭。
- **玩家/NPC 人物：Q版卡通风**。大头小身、饱和色、表情化。服装分套用ai绘制（男女两版），不靠立绘色相旋转，也不复用保安色块。钓点用**背向水面的坐姿**，正面立绘留给装备/登录/潜入。
- **钓鱼点**：分层码头（远山 / 岸树 / 水面 / 木板），水面有十字闪点与跳鱼；红白浮漂按甩杆力度走抛物线；上钩出现感叹号气泡（星露谷式提示）。鱼塘偏静水荷叶，清溪池偏冷色碎浪。
- **统一 prompt 模板（鱼）**：固定风格描述前缀（如 "chibi cartoon style, flat saturated color, white background, centered, game asset"）+ 主体描述，确保 16 鱼 + 装备风格一致。
- 资产规格：鱼 PNG 透明底、512×512；装备图标 128×128；UI 走矢量/SVG 自绘，不依赖 AI。人物为运行时矢量绘制，不进 AI 流水线。

## 理由

- AI 生图是 Demo 阶段拿到"能看"资产的最快路径，外包约稿慢且贵、免费素材包风格难统一、自做矢量量产 16 鱼工作量大。
- Q版卡通风在 AI 生图上一致性最可控（写实风易跑偏、国风水墨与休闲调性冲突、扁平矢量缺鱼质感），且与"休闲养成"调性契合。
- 人物若跟鱼同一套大头 Q 版，钓点里看不清甩杆/浮漂距离；改农场主比例是为了读动作，不是改玩法。
- UI 用矢量自绘而非 AI：UI 图标需要精确像素对齐与可缩放，AI 生图不适合；只在鱼和装备插画上用 AI。

## 影响

- 需建立 prompt 模板仓库与资产命名约定（如 `fish_{id}.png`、`rod_{id}.png`），便于 v0.2 扩到 62 鱼时复用模板。
- 资产先占位（灰色剪影）跑通流程，AI 生图作为独立流水线并行补图，不阻塞代码开发。
- 人物模板改比例后，潜入/装备预览/登录小人共用同一套绘制函数，避免再分两套身体。
