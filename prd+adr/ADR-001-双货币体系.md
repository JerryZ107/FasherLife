# ADR-001：双货币体系（金币 + 珍珠）

- 状态：已接受
- 日期：2026-08-10
- 关联：设计案第 9.1 节、ADR-007

## 背景

原设计只有金币一种货币，装备、渔场、鱼饵全部用金币，经济是封闭循环：玩家自产自销，没有真钱出口，商业化无从谈起。

## 决策

- 引入第二货币**珍珠**作为充值货币。汇率：**1 珍珠 = 1 元**；**1 元 = 100 金币**。
- 金币：游戏内产出（卖鱼、月卡），用于入场费、金币装备、鱼缸、鱼饵。
- 珍珠：充值产出，用于加速卡、同品质珍珠鱼竿、限定外观、鱼筐。同品质珍珠竿与金币竿数值持平。
- 金币可用珍珠兑换（珍珠→金币商店汇率为1：100）。

## 理由

- 单一货币无法承载"玩出来的"与"买来的"两类价值，容易退化成数值直接交易。
- 双货币是休闲品类标准做法，天然隔离游戏内经济与付费，也方便后续活动发币。

## 影响

- 存档新增 `pearl` 字段；商城 UI 拆分金币价 / 珍珠价。
- 后续所有付费点基于珍珠定价（见 ADR-003 ~ ADR-006）。
