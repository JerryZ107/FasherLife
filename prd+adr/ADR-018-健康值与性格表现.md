# ADR-018：健康值、性格与爱情观

- 状态：已接受
- 日期：2026-08-20
- 关联：PRD-001 玩法设定、ADR-010 数值克制、ADR-012 钓鱼小游戏、ADR-015 鱼缸与鱼卵、ADR-017 双路线
- 修正：ADR-015 不做配偶观、每日 0.42 下卵、孵化 2 天；ADR-012 全鱼同一套正弦+噪声（难度仍由品质驱动，本 ADR 加花样）；性格加权 温顺 35% / 暴躁 25% / 高冷 25% / 胆小 15%（爱情观仍各 25%）

## 功能分析

健康接到售价和孕期，喂食才有账。性格只改滑块轨迹和缸内表现，难度仍归品质和装备。缸内花样（怒火、受惊位移）只在点到该鱼时播一下，不常驻、不循环。爱情观看品质不看种类，用分缸解决配不上，不恢复指定对象。求偶香只加快已合格的对，不改谁接受谁。子代只遗传种类，性格和爱情观重掷。

## 切片

1. 健康 → 售价、孕期、缸内游速（先做）
2. 四性格：滑块花样 + 缸内表现
3. 四爱情观 + 求偶香成功率 / 5 分钟产卵 + 孵化 6～7 天

性格、爱情观互斥、不叠加、不洗练。

## 存档字段（`TankFish` / 配对）

| 字段 | 类型 | 何时写入 |
| --- | --- | --- |
| `health` | 0～100 | 入缸 100；已有 |
| `personality` | `hot` / `docile` / `timid` / `aloof` | 生成实例时加权：温顺 35%、暴躁 25%、高冷 25%、胆小 15% |
| `loveView` | `peer` / `aspire` / `any` / `none` | 四选一，各 25% |
| `pairId` | string / null | 配对成功；上限 1 |
| `gestationLeft` | 游戏天，整数 | 结成时写入；≤60 暂停不减 |
| `scentLayAt` | 现实时间戳 ms / 0 | 求偶香买孕期时写入，到期下卵 |

筐内鱼可在入缸或第一次展示时再掷性格/爱情观，之后锁定。鱼行买来的活鱼、孵化出苗：生成时掷。

子代：`defId` = 亲本之一 50/50；`sex`、`personality`、`loveView` 独立随机。不抄亲本性格/爱情观。

## 1. 健康

扣减沿用 PRD-001：当天没喂 −1；健康 <60 改为按 2 的指数扣；缸内每条死鱼再 −1；到 0 死亡、解配。

### 1.1 售价

仅「售卖给鱼行」。挂售默认填这个价，玩家可改。

```
alive:  price = max(ceil(baseSell * 0.10), round(baseSell * health / 100))
dead:   不能售卖、不能挂售、不能做菜；已不是持有物，缸内虚化，只能清理去掉画面
basket: 无健康，price = baseSell
```

`baseSell` = `FISH_DEFS.sellPrice`。

### 1.2 孕期（替换每日 0.42）

结成当天 `H = min(双方 health)`，写入 `gestationLeft = gestationDays(H)`。之后每个游戏天（ADR-017 结算第 4 步）：

```
H = min(双方当前 health)
if 任一方已死或已解配: 清 gestationLeft，不再下新卵（缸底已有卵保留）
else if H <= 60:        不减天数（暂停）
else:
  target = gestationDays(H)
  gestationLeft = min(gestationLeft, target)
  gestationLeft -= 1
  if gestationLeft <= 0 且该缸卵数 < 6: 下 1 卵，然后按当前 H 重新写入下一轮 gestationLeft
```

`gestationDays(H)`：

| H | 天数 |
| --- | --- |
| ≤60 | 不下卵（暂停） |
| 61～70 | 6 |
| 71～80 | 5 |
| 81～85 | 4 |
| 86～89 | 3 |
| 90～94 | 3 |
| 95～100 | 2 |

同一对下完一卵后立刻开始下一轮孕期，不要求重新配对。健康变好可缩短剩余；变差不加长，只在 ≤60 暂停。

### 1.3 缸内游速

游速 100 的原模长 = 0.70。全体再乘缩放，仍与健康挂钩：

```
speedMul = (health / 100) * personalitySpeed
scale    = 暴躁 ? 1/2 : 1/3
模长     = 0.70 * speedMul * scale
死鱼     = 0，沉底（已有）
```

温顺 / 胆小 / 高冷为原速度的 1/3；暴躁为原速度的 1/2（仍快于其他性格）。

| 性格 | `personalitySpeed` |
| --- | --- |
| 暴躁 `hot` | 1.35 |
| 温顺 `docile` | 0.70 |
| 胆小 `timid` | 1.00 |
| 高冷 `aloof` | 1.00 |

## 2. 性格

品质 `motion`（滑块大小、振幅、频率、噪声、speed）只由品质决定，装备照旧抵消（ADR-012）。性格改目标怎么动，不改 `sliderSize`。

底：`target = 0.5 + sin(t * freq * 2π) * amp + (rand-0.5)*noise*0.3`，再追目标。  
滑块 Y：0 为槽顶，1 为槽底，夹紧 0.05～0.95。

游速系数始终生效。缸内可读花样只在玩家点到该鱼时播一次，播完消失；未点选时与普通鱼一样游，无标记、无周期性瞬移。再点同一条再播一次。点鱼本身选中并播花样；点空白水域才取消选中。**界面不打性格标签**；性别和爱情观要持有商城书籍「养鱼手册」才显示。

| 性格 | 小游戏（上钩后） | 缸内（点到该鱼时） |
| --- | --- | --- |
| **暴躁** | 不用正弦。在 0.12 与 0.88 之间匀速折返，单程 `0.40 / motion.speed` 秒。**两端都停留 1.8s** 再折返。滑块带淡出轨迹。 | 点选**不位移**。头顶用 Graphics 画井字青筋发火表情，持续 **3 秒**；这 3 秒内缸内游速 ×2。不要贴图、不要打火机火苗。 |
| **温顺** | 正弦保留，`noiseWeight` 视为 0；`frequency *= 0.55`。`fishVel` 阻尼可用 0.80。 | **仅温顺**选中期间位移 ×0.12。其他性格选中只画圈，不减速 |
| **胆小** | 每 0.35～0.70s 另选目标 `clamp(fishY + (rand*2-1)*0.40)`，用 0.28～0.48s 缓出滑过去，禁止瞬移。 | 点中后沿直线**位移**冲出 80～140px（约 0.4s，夹游动区），带淡出水痕轨迹，要能看见运动过程，禁止瞬移。到位后轻微抖动 **4 秒**（原 2s ×2）。 |
| **高冷** | 底运动用品质正弦+噪声。贴上玩家滑块（`abs < min(sizes)*0.25`）且冷却 ≥0.80s 时，向远离玩家方向滑 `0.22`（约 0.34s 缓出），带轨迹，禁止瞬移。 | 点选仍开操作栏和选中圈；vx/vy 不因选中改变 |

挂机不播小游戏，性格不影响挂机产鱼。

## 3. 爱情观与自动配对

硬条件（全失败则不再看爱情观）：同缸、一公一母、双方未死、双方 `pairId == null`（上限 1）。

### 3.1 接受函数（双方都要过）

`qualityRank`：普通 0 … 极品 4。

```
accept(self, other):
  none   → false
  any    → true
  peer   → quality(self) == quality(other)
  aspire → qualityRank(other) > qualityRank(self)
```

配对当且仅当 `accept(A,B) && accept(B,A)`。硬过滤失败的组合禁止用软骰放行：

| A \ B | 门当户对 | 慕强 | 来者不拒 | 拒绝配对 |
| --- | --- | --- | --- | --- |
| 门当户对 | 同品质才行 | 不行 | 同品质才行 | 不行 |
| 慕强 | 不行 | 不行 | 对方品质 > 慕强自己 | 不行 |
| 来者不拒 | 同品质才行 | 自己品质 > 对方慕强 | 行 | 不行 |
| 拒绝配对 | 不行 | 不行 | 不行 | 不行 |

### 3.2 软骰（仅已互相接受）

```
p = 0.82
if 任一方不是「来者不拒」且不同种: p -= 0.28
if 双方都是「来者不拒」: 不扣种类、不扣品质差
elif 有「慕强」或「门当户对」: 不扣品质差
else: p -= abs(qRankA - qRankB) * 0.16
p += 求偶香加成（缸雾 + max(两条鱼加成)，现 attractBonusForPair）
p = clamp(0.08, 0.92, p)
掷 rand < p 则 bindPair，gestationLeft = gestationDays(min health)
```

每日每缸：未配公按 `uid` 排序，各只试到第一对成功的母（现 `tryAutoPairTank` + 爱情观）。

### 3.3 求偶香

不改 `accept()`。拒绝配对的鱼加香也不进入候选。

| 效果 | 何时 | 做什么 |
| --- | --- | --- |
| 压拒绝 | 香还在持续天数内 | 只加软骰 `p`，封顶 0.92 |
| 买时间 | 金币香对该鱼 / 珍珠雾对该缸，且目标**已有配偶** | `gestationLeft` 清零；`scentLayAt = now + 5min`。到点且仍配对、双方活、缸卵 <6 → 下 1 卵，再按当时 H 开下一轮孕期 |

5 分钟为现实时间，不套用游戏天。未到点解配/死亡：取消这次下卵。

金币香喂一条、珍珠雾喷整缸、持续天数：`attractantDefs`。

## 4. 孵化

点卵 → 扣金币（`HATCH_GOLD[亲本较高品质]`）→ 开工。

```
hatchDays = (较高品质 ≥ 稀有) ? 6 : 7
readyDay  = gameDay + hatchDays
```

加速：1 珍珠或 1 次广告 → `readyDay -= 1`（已到期不再减）。可叠。挂售卵沿用 ADR-015；买回家的卵不要求本缸有对应配偶。

## 实现

- 删除每日 `EGG_LAY_CHANCE = 0.42`；`HATCH_DAYS = 2` 改为 6/7。
- `rollPairAccept` 先 `accept` 再软骰；文案区分硬过滤失败 / 没看对眼。
- `FishingCanvas` 按 `personality` 分支目标函数；品质 `motion` 仍传入。
- `TankCanvas`：模长 = 0.70×健康×性格×（暴躁 1/2，其余 1/3）；选中 ×0.12 仅温顺；暴躁点选 Graphics 发火表情 3 秒且游速 ×2；胆小位移带轨迹，禁止瞬移；高冷不减速。
- 结算顺序见 ADR-017 第 5 节。
- 不做性格叠加、不多配偶、子代不遗传性格/爱情观/性别。
