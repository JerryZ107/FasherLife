# PRD-003：新手引导

> 产品需求：新手引导的目标、流程、文案、状态机与边界处理。
> 技术实现见 `src/game/guide.ts`、`src/game/guidePhase.ts`、`src/store/gameStore.ts`。
> 任务线定义见 `src/data/questDefs.ts`，存档字段见 `src/save/saveSchema.ts`。

---

## 1. 目标与范围

### 1.1 目标
新存档赠送 3 条普通鱼（白条+青鱼+河豚，2 公 1 母）和 1 枚普通卵，让首次进入游戏的玩家在 **不读任何说明文字** 的情况下，独立完成一次完整闭环：

> 喂食（起始鱼）→ 卖鱼 → 翻图鉴 → 钓鱼 → 入缸 → 买鲫鱼做菜吃菜 → 圣殿排行参观

并在闭环中自然学会：点鱼喂食、把缸鱼存回筐去鱼行卖鱼、去商城买鱼粮、打开图鉴、地图选渔场、进钓点、甩竿收竿、开鱼筐存缸、做菜补体力、圣殿排行参观。

### 1.2 范围
- **做**：界面高亮 + 一句话提示卡，跟着新手任务线 `q_feed → q_sell → q_read_encyc → q_go_fish → q_catch → q_tank → q_buy_carp → q_cook → q_eat → q_visit_temple → q_done` 走。
- **不做**：剧情对白、强制锁屏教学、配音、多分支引导。
- **任务页**：引导进行中「新手引导」页签靠前；**引导完成后**移到「常驻任务」后边，默认打开「新手任务」。

### 1.3 设计原则
1. **一次只说一件事**：每屏只高亮一个目标 + 一句动作指令。
2. **跟着状态走，不跟着点击走**：以 `questStep` + `guideTripPhase` 为准，玩家可以乱点，引导会自动回到当前该做的事。
3. **回程优先**：钓到鱼后，无论任务步在哪，都优先引导回馆存缸，避免"钓完又让钓"的死循环。
4. **可跳过、可重温**：跳过后界面引导消失，任务线仍在任务页；重温时按 `reviewStep` 重放历史步。
5. **先欢迎再问**：新玩家首次进游戏先弹欢迎，再问「是否需要新手引导」。未回答前（`guidePrompted=false`）不显示任何引导；选「自由探索」即 `guideSkipped=true`。
6. **自由探索不拦截**：玩家点进非闭环页面（任务/邮件/商城/装备/做菜/图鉴/圣殿/参观/潜入）时不再弹「先做完这步」也不高亮返回键，引导只在闭环相关场景显示。

## 2. 状态机：guideTripPhase

钓鱼是一个跨场景的闭环，单靠 `questStep` 无法区分"刚钓到鱼该回馆"还是"还在钓"。引入 `guideTripPhase` 跟踪玩家在闭环里的位置：

| 值 | 含义 | 进入条件 |
| --- | --- | --- |
| 0 | 空闲 | 默认 / 完成闭环后 |
| 1 | 馆 → 地图 | 水族馆 → 钓鱼地图 |
| 2 | 地图 → 钓点 | 钓鱼地图 → 钓鱼点 |
| 3 | 钓点 → 地图 | 钓鱼点 → 钓鱼地图（钓完离开） |
| 4 | 地图 → 馆 | 钓鱼地图 → 水族馆（待存缸） |
| 5 | 鱼筐 → 馆 | 存完缸后（待喂食）— 新流程主线路不再触发，仅兜底 |

### 2.1 优先级
`currentGuide` 判定顺序：

1. `phase === 5` → 喂食引导（`feedTripBeat`）— 新流程主线不再置 5
2. `phase === 3 || 4` → 回程存缸引导（`tankQuestBeat`），**屏蔽钓鱼地图的"进清溪"提示**
3. 否则按 `questStep` 走对应分支

### 2.2 相位流转规则
- 进水族馆时若 `guideTripPhase === 4`，**保持 4**（不回 0），让玩家继续被引导去开鱼筐。
- 存缸成功（`putManyToTank`）后 `clearGuideTrip` → 相位回 0。新流程 `q_tank` 是最后一步，完成后即 `q_done`，不再置 5。
- 喂食成功后相位回 0。
- 新流程 `q_feed` 是第一步（起始鱼已在缸），不涉及回程，相位全程为 0。

## 4. UI 规范

### 4.1 引导卡片
- 卡片含 **标题**（粗体）+ **正文**（一句话动作）。
- 「跳过」按钮位于卡片 **右上角**（不是页面右上角），颜色与卡片区分。
- 有 `target` 时卡片自动躲开高亮元素；无 `target` 时按 `place`（top/bottom）定位。
- 钓鱼点内的节拍一律 `place: bottom`，避免遮挡顶部「返回 / 挂机 / 换饵」按钮。

### 4.2 高亮与暗罩
- `dim: true`：高亮目标外铺半透明暗罩，引导玩家视线。
- `dim: false`：只高亮不铺罩（用于存缸/存筐等需要看到列表的步骤）。
- 无 `target`：不铺罩，只显示卡片。

### 4.3 跳过与重温
- **跳过**：`guideSkipped = true`，界面引导消失，任务线仍可在任务页查看。
- **重温**：在任务页点历史任务，置 `guideReviewStep`，`currentGuide` 改用 `reviewStep` 而非 `questStep` 重放该步。
- 任务推进时 `applyQuest` 清掉过期的 `guideReviewStep`。
- `resumeGuide` 处理 `q_tank` → phase 4（回程存鱼）；新流程 `q_feed` 是第一步，不再设 phase 5。

## 5. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 玩家在引导中跳到非闭环页（装备/做菜等） | 自由探索，不显示引导（E1 已移除） |
| 新玩家首次进游戏 | 先弹欢迎 → 问「是否需要新手引导」；未回答前 `guidePrompted=false` 抑制引导 |
| 玩家钓到鱼后没回馆，又点进清溪 | phase 3 已置，`fishingMapBeat` 走 B1 而非 A2 |
| 玩家存完缸没喂食就跑去钓鱼 | phase 已回 0，按 `questStep=q_feed` 走 C 分支 |
| 玩家跳过后又想看引导 | 任务页重温，置 `reviewStep`，不受 `guideSkipped` 影响 |
| 旧存档没有 `guideTripPhase` 字段 | `normalizeSave` 按 `guidePendingStore` / `questStep` 推断初值 |
| 旧存档已有进度 | `normalizeSave` 将 `guidePrompted` 默认置真，不再强弹欢迎 |
| 钓获弹窗未关就点返回 | A9 优先于 A10，先引导关弹窗 |
